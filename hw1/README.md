## Правила и контракт
Выдача запрещена, если экземпляр занят или у читателя есть активная просрочка. Срок по умолчанию 14 дней, разрешены 1–60 дней. Возврат фиксирует текущую дату; повторный возврат — конфликт. Просрочка = max(0, дата возврата или сегодня − срок). Штраф 10 руб./сутки (принятое правило проекта). Дата определяется сервером PostgreSQL / Python; перед сериями проверить их совпадение. Историческая просрочка возвращённой книги не препятствует новой выдаче. Сводка считает активные/просроченные выдачи и топ-10 книг по всем выдачам.

Все API требуют Basic Auth. JSON; даты в ответах Flask представлены строками HTTP-date в GMT. Ошибка: `{ "error": "описание" }`. Авторизация проверяется на каждом запросе; отдельной операции login нет. HTML `/` — оболочка интерфейса, не операция API.

Поле cover хранится в БД; тестовые значения — PNG размером 1×1 пиксель. Наполнитель пересоздаёт только четыре таблицы в персональной схеме и генерирует данные формулами без случайности. **Команда seed удаляет текущие выдачи; применять только к учебной базе.** Даты исторических выдач фиксированы, последние 10% активны. Данные одинаковы при повторе, но статус просрочки зависит от даты испытания — обе серии выполнять в один день.

## Замеры
```bash
docker compose exec app python seed.py small
docker compose exec app python measure.py small
docker compose exec app python seed.py work
docker compose exec app python measure.py work
docker compose exec app python -m pip freeze > results/versions.txt
docker compose exec db postgres --version > results/postgres-version.txt
docker compose ps > results/containers.txt
```
Один прогрев и 20 повторов каждой операции, последовательно, без параллельной нагрузки. Фильтр снимается отдельно. Basic Auth одинаков во всех запросах. Сохраняются все 120 отсчётов на каждом объёме, p50 — медиана, p95 — ближайший ранг ceil(0.95*n). Замеры выполняются внутри app-контейнера, исключают браузер. Закрыть браузер на время испытания. Перед обеими сериями убедиться, что машина и режим питания одинаковы; записать CPU/RAM/ОС и версию Docker.

Вызовы БД измеряются таймером вокруг execute + fetchall, без соединения, SET search_path, commit. Их время включает драйвер и передачу результатов, а не только выполнение SQL сервером. X-App-MS — серверное время до отправки, включая соединение и commit; X-DB-MS — сумма вызовов; X-DB-Queries — число SQL предметной операции. total_ms — полное время клиента; total_ms − server_ms включает транспорт и чтение ответа. code_ms = server_ms − db_ms: весь остаток, включая соединение и транзакцию, **не чистое CPU-время Python**. Для разложения сравнивать отсчёты одного запроса; медианы частей могут не складываться в медиану общего.

Перед записью замерщик добавляет одного читателя и 21 свободный экземпляр. Выдача добавляет 21 запись (прогрев + 20), возврат меняет их, без новых строк. До и после сохраняются реальные COUNT(*). Измерения чтения идут до выдач; их объём: базовый + 1 читатель + 21 экземпляр, без дополнительных выдач. Перед повтором measure снова выполнить seed соответствующего объёма. Без этого серии не сопоставимы.

В results/small.json и work.json находятся исходные результаты. При ошибке HTTP замер прекращается: нельзя включать ошибочные ответы в серию успешных операций. Подтверждение времени и числа SQL — заголовки ответов; исходные SQL находятся в app.py.
